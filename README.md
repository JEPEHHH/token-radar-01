A launch radar for the [token-radar-01 bounty](https://make.fun/bounty/token-radar-01): it reads the sealed snapshot, scores every protocol on its own figures (liquidity, holder spread, volume growth, maturity) and writes a ranked board of 226 rows from 758 protocols, a static dashboard, screenshots and a dossier. Node 22.18+, standard library only, no install step and no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
